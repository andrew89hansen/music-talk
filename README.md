# Music Talk

Welcome to music talk! This repo will be a simple blog to post about specific artists, albums, history, or anything music related.

## Structure 

All posts live within the `_posts` directory.

If discussing a band, the structure will be as follows: `_posts/{band name}/{your name}/YYYY-MM-DD-{title}.md`

Post title structure requires dashes instead of spaces: `Cool blog post.md` -> `cool-blog-post.md`.

## Content 

All content must live within an `.md` file. 

Frontmatter required for each post:

```markdown
---
title: Title of post
date: YYYY-MM-DDD
---

// Page content 
```

To add a post, open a pull request for your article to be added.
